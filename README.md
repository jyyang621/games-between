# 怀旧小游戏

项目首页名称为「花自飘零的游戏空间」。本目录管理独立数独网页版与微信小游戏合集，Git 历史保留在外层 `.git/`。

微信小游戏已接入数独、黄金矿工、Zuma、2048、扫雷、五子棋、俄罗斯方块和华容道八款游戏，大厅每页三款，2048、扫雷与五子棋位于第二页，俄罗斯方块和华容道位于第三页。华容道为4×5曹操脱困，支持三种固定开局、选块方向按钮或拖动、逐格计步与撤销、暂停和本机续局，详见 [华容道规则与接入说明](数独/docs/huarongdao.md)。俄罗斯方块支持七袋出块、旋转与落点预览、软降/直落、消行计分及逐级加速、暂停与本机续局，详见 [俄罗斯方块规则与接入说明](数独/docs/tetris.md)。五子棋支持简单／普通／困难三档人机、同机双人、先后手切换、悔棋、暂停与本机续局，详见 [五子棋规则与接入说明](数独/docs/gomoku.md)。扫雷详见 [扫雷设计与验收说明](数独/docs/minesweeper.md)。

│  ├─ index.html

根目录的 `.github/`、`.gitignore`、`AGENTS.md` 和 `package.json` 是仓库及统一开发入口。原项目资料保留在 `数独/` 内，构建工具通过相对路径读取同级微信工程；后续移动整个外层目录无需再改源码。

## 构建、测试与本地预览

需要 Node.js 20 或更新版本。在本目录运行：

```sh
npm run build:wechat
npm run check:wechat
npm test
npm run build:preview
npm start
```

网页版入口为 <http://127.0.0.1:4173/>，小游戏浏览器预览为 <http://127.0.0.1:4173/preview/>。端口占用时用环境变量 `PORT` 指定其他端口。脚本和测试的实际维护位置在 `数独/scripts/`、`数独/tests/`；也可以进入 `数独/` 后执行同名 npm 命令。

用微信开发者工具导入 `D:\怀旧小游戏\微信小程序`，保留已有 AppID 和 `project.private.config.json`。浏览器预览只能用于本地 QA，微信工具和真机验证仍需独立执行。

## 仓库范围

仓库包含 `数独/` 的网页版、脚本、测试和文档，以及 `微信小程序/` 的运行源码、vendor 维护源和运行音乐。克隆后可直接执行构建检查和测试；生成浏览器小游戏预览时先运行 `npm run build:preview`。

旁边的 `黄金矿工/`、`祖玛Zuma/` 是独立原项目，`音频/` 保存原始大音频，均不纳入本仓库。微信私有配置、开发工具缓存、`artifacts/`、本机源码快照和临时 Notion 准备文件也不提交。运行音乐及其来源清单随微信工程保留，普通构建和测试无需原始音频、FFmpeg 或旁边的独立原项目。

`.gitattributes` 统一普通文本的换行，并对来源哈希覆盖的 vendor、生成核心和音乐准备脚本保留原始字节，避免 Windows 与 GitHub 检出时的换行转换破坏校验。
