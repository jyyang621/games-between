# 游戏之间 · 微信小游戏工程

本目录可直接使用微信开发者工具导入，工程类型为「小游戏」。包含数独、黄金矿工、Zuma、2048、扫雷、五子棋、俄罗斯方块与华容道八款本地游戏。

- `game.js` 启动 `src/main.js`，由通用宿主加载注册表与游戏模块。
- `src/app/`、`src/platform/`、`src/hub/` 分别管理宿主、微信能力与大厅。
- `src/games/` 保存各游戏规则、控制、渲染、生成核心和题库。
- `assets/audio/` 保存运行音乐与来源清单，`vendor/` 保存移植维护源、生成器、许可及哈希。

无需安装第三方运行依赖。请保留已有 AppID；`project.private.config.json` 属于本机配置，不进入 GitHub。原游戏 ID、存档键和分享参数不变。

新增游戏通过 `src/registry.js` 和统一游戏契约接入，避免向宿主增加游戏专属模型。生成核心应修改维护源后重新生成并核对来源哈希。

工程详情与导入方法见[仓库说明](../README.md)。微信工具、真机、真实分享、上传、审核及正式发布需要分别验收。
