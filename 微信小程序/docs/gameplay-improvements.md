# 黄金矿工与扫雷：随机性和操作节奏

## 玩法依据

- [Minesweeper Online 的官方玩法](https://minesweeper.online/help/gameplay)说明：数字周围旗数吻合时可点击数字连开，减少逐格点击；胜利条件是翻开全部非雷格，并非必须插满旗。
- [PlayMinesweeper 的官方教程](https://www.playminesweeper.com/how-to-play)说明其版本首格及邻格安全，空白递归展开到数字边界，手机长按插旗，错误旗帜可能使连开触雷。不同版本的首开保护有所不同，本项目继续保留原有的一圈保护。
- [GAMENINJA 自有 Gold Miner 版本的玩法](https://gameninja.com/games/gold-miner)说明抓钩抓到路径上的第一个物件，重石拖慢回收，TNT 桶摧毁周围物件；随身炸药用于炸掉已抓住的物件。这支持保留瞄准、遮挡、重量与局部爆炸的取舍。

这些资料说明玩法，不提供 Flash 原版的关卡生成源码。本次随机布局与首开筛选是为本仓库设计的改进，不声称复刻某个原版算法。游戏数值、存档键、分享参数和微信 AppID 不改变。

## 黄金矿工

- 原来的闯关使用固定坐标，拓展关/无尽的金钻按两行交替排列，TNT 位置选择很少。新冒险使用种子和关卡号生成连续随机坐标，金钻不再固定在原有行列，TNT 也会换位置。
- 保留每关物件种类、数量、价值、目标、时间和新机制的引入顺序。新冒险换种子，重试和继续同一冒险保持布局，避免靠反复重试刷新有利地图。
- 新冒险记录布局版本 2。已有闯关和无尽存档继续使用原布局算法，不会因升级换盘；要体验新布局，请选择“开启新的挑战”。扫雷同样需要开始新局才使用新的首开筛选。
- 同时检查横竖屏初始间距、边界和抓钩范围。移动角色仍走各自矿道；有精灵时，大金块和钻石保持在矿道上方。
- TNT 必须威胁附近的宝物，同时保留目标值 115% 的静态安全价值余量，避免纯随机把所有关键宝物聚在炸药旁。价值余量不等于保证在时限内通关。
- 布局采样有次数上限和经过测试的备用序列；关卡定义缓存后复用，商店绘制不会每帧重新生成。

详见[随机矿区维护说明](../vendor/gold-miner/README.md)。测试覆盖全部 40 关的 128 个种子，以及无尽早期、后期和最高层。额外 50,000 张矿区压力抽样未出现生成失败，本地 Node.js 下生成耗时 P99 约 0.21ms。手机端性能仍需真机验收。

## 扫雷

原先的空白扩散和数字连开算法已存在，主要体验问题是初级首开常展开很大，且连开只能在“翻开”模式使用。

- 新棋盘仍延迟到首次翻开时布雷，首格和周围一圈无雷。最多抽取 64 张完整随机棋盘，优先采用首开面积不超过安全格数 30% 的盘面：初级 21、中级 26、高级 45 格。若未找到，选此次抽样中首开最小的一张。
- 这不是硬上限：极少数初级局面仍可能超过目标。不会截断空白扩散，后续点击零格仍完整展开。数字格本来只展开自身；批量操作靠推理后连开。
- 两种模式均可轻点已翻开的数字。周围旗数正确即展开其余相邻格；旗数不符不操作，旗位置错误仍会触雷。
- 长按未翻开的格子 450ms 插旗/取消，保留模式按钮。短按在抬手后执行，长按不再额外翻开。滑离格子、取消、暂停、换难度或改变屏幕尺寸时取消待处理手势。
- 已有版本 1 的棋盘保留原布雷算法，恢复时不换盘。新局使用版本 2。仍是可能需要猜测的随机棋盘，不是“无猜模式”。

### 可重复的首开抽样

每档使用种子 0–999，各取左上、右上、中央及右下四个首点，共 4000 盘；比较完整空白扩散后的格数。此结果是抽样，并非所有种子的硬保证。

| 难度 | 旧均值 → 新均值 | 旧 P95 → 新 P95 | 新样本最大值 |
| --- | --- | --- | --- |
| 初级 | 32.36 → 11.84 | 59 → 21 | 30 |
| 中级 | 20.66 → 13.03 | 50 → 25 | 26 |
| 高级 | 19.54 → 16.65 | 52 → 39 | 45 |

本地 Node.js 抽样的平均生成耗时低于 0.1ms；这不是微信手机端性能承诺。

## 验证

在 `微信小程序/` 运行：

```sh
npm run check
```

规则测试覆盖种子复现、数量和边界约束、旧扫雷存档、空白扩散、正确/错误旗的连开，以及实际宿主事件路径上的短按、长按、取消、滑开、暂停、切后台和横竖屏导航。黄金矿工生成文件必须由维护源重新生成；`check:generated` 同时检查黄金矿工和 Zuma 的来源哈希。

微信开发者工具和真机仍需人工验收：

1. 导入本目录，用现有 AppID 编译。分别开始黄金矿工闯关和无尽，重开新挑战检查布局变化，重试本关和恢复存档检查布局稳定。
2. 黄金矿工切换横竖屏，检查物件是否可见、可抓且初始不重叠；观察 TNT 红圈、连锁爆炸、移动猪与小精灵，并检查商店没有明显卡顿。
3. 扫雷三档分别从边角和中间开始；检查正常空白展开。长按插旗后不应额外翻开，在两种模式点击数字均可连开。
4. 扫雷按下后滑开或切后台再返回，不应误翻格；暂停/恢复和换难度确认框应保持正常。已有存档应能恢复。
5. 大厅八款游戏各进入一次，检查页面、音乐开关、分享与返回大厅。真实分享、上传、审核和正式发布仍是独立步骤。
