# games-between · 游戏之间

微信小游戏合集，首页名称为「花自飘零的游戏空间」。包含数独、黄金矿工、Zuma、2048、扫雷、五子棋、俄罗斯方块和华容道八款本地游戏。

本仓库只保存微信小游戏工程及运行资源。独立网页版、浏览器预览、历史文档、原始大音频和本机开发资料不纳入当前版本。

## 导入微信开发者工具

1. 克隆仓库，使用微信开发者工具导入 `微信小程序/` 目录。
2. 工程类型选择「小游戏」，使用已有 AppID，并确认当前微信账号具有开发权限。
3. 点击编译进入大厅；需要手机验证时使用开发者工具的预览功能。

工程不需要 npm 安装、网站服务器或业务接口。`project.private.config.json` 由开发者工具在本机管理，不提交到 GitHub。

## 工程结构

```text
微信小程序/
├─ game.js                 微信启动入口
├─ game.json               小游戏配置
├─ project.config.json     公开工程配置
├─ src/
│  ├─ app/                 通用宿主、游戏接口与输入
│  ├─ platform/            微信平台、存储与音乐
│  ├─ hub/                 大厅与分页
│  ├─ registry.js          游戏注册表
│  └─ games/               八款游戏各自的规则、控制与渲染
├─ assets/audio/           两首运行音乐与来源清单
└─ vendor/                 移植维护源、生成器、许可及来源哈希
```

游戏共享大厅和平台能力，各自维护独立状态与存档；原 AppID、游戏 ID、存档键及分享参数保留。大厅每页三款，返回大厅或进入后台时暂停，继续游玩由玩家手动恢复。

运行使用仓库内的 JavaScript 核心和音乐文件，无需旁边的原游戏项目或原始大音频。来源哈希覆盖的 vendor 与生成核心通过 `.gitattributes` 保留原始字节。生成核心应从维护源重新生成，避免直接修改产物。

当前仓库提供可导入源码；GitHub 上传与微信上传、审核和正式发布是独立步骤。
