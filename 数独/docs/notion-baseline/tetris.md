## 计划与当前实现

用户要求在合集新增俄罗斯方块。首版单人无尽玩法已实现，稳定 ID <code>tetris</code>，第七款游戏、大厅第三页。10×20 棋盘，七种方块、左右移动、顺时针旋转、软降／直落、下三块预告、幽灵落点、消行计分、等级加速、本机最佳、暂停、确认重开与续局。

本地自动检查和微信开发者工具实操通过；手机真机与正式发布仍未完成。当前为未提交工作区，不以旧 HEAD 表示完整实现。

## 规则、算法与参数

| 项目 | 实现 |
| --- | --- |
| 棋盘 | 10 列×20 可见行；允许顶部两行隐藏空间 |
| 方块 | I、O、T、S、Z、J、L，Mulberry32＋Fisher–Yates 七袋，每袋各出现一次 |
| 队列 | 内部保留 5 块、界面预告前 3 块；袋余量 0～6 块 |
| 消行 | 单次 1／2／3／4 行计 100／300／500／800×锁定前等级 |
| 手动下降 | 软降每格 1 分；直落每格 2 分并立即锁定 |
| 等级与速度 | 每 10 行升一级，最高 20；下落间隔为 max(80, round(800×0.82\^(level−1))) 毫秒 |
| 落锁 | 触地 500ms；同一块触地后成功左右移动／旋转最多重置 15 次 |
| 时钟 | 宿主 tick 驱动；单帧补算上限 100ms，不在后台补算整段离开时间 |
| 顶出 | 锁定时仍有格子在可见棋盘上方即结束且不清行；下一块无法出生也结束 |

旋转使用有限普通墙／地面踢位，依次尝试 (0,0)、(-1,0)、(1,0)、(-2,0)、(2,0)、(0,-1)、(-1,-1)、(1,-1)、(0,-2)；O 块旋转无变化。不是完整 SRS。生成锚点 y=-1，碰撞允许最低隐藏坐标 y=-2。计分饱和于 Number.MAX\_SAFE\_INTEGER，避免极值加分溢出。

## 操作、界面与生命周期

按钮为左移、旋转、右移、软降和直落；软降一次下移一格。棋盘点按旋转、左右滑动移动、下滑逐格下降。手势阈值是一格宽与 12 逻辑像素的较大值，每次事件最多移动 10 格／下降 20 格，额外触点取消手势，上滑不会旋转。

暂停、返回大厅、后台、分享、旋屏后手动继续，掉落和落锁均停止；合法存档重启恢复也先暂停。进行中重开须确认，取消保留棋盘并暂停。音乐复用宿主共享播放器，仅未暂停的进行中局面播放。

绿／奶油配色、彩色方块和幽灵落点；支持安全区与宿主胶囊／音乐保留区域。四种尺寸已做离屏目视核对，手机上的短屏可读性和误触仍待验收。

## 架构、数据与迁移

<code>微信小程序/src/games/tetris/engine.js</code> 管理纯规则和快照校验，<code>index.js</code> 管理手势、重力、落锁、确认和存档，<code>renderer.js</code> 管理 Canvas 与命中区域。仅通过注册表接入，没有宿主、平台或公共契约专属分支。直接维护 CommonJS 源，由原构建依赖图生成入口与预览，无新增 vendor 核心。

新槽 <code>games-between:tetris:save:v1</code>、外层 version 1，保存 round、best、timing。timing 包含 fallMs、lockMs、lockResets，恢复按范围校验，暂停／重启不会重新赠送落锁调整次数。每累计一秒有效游戏时间，以及落锁、暂停、重开、有效手势结束和宿主 save 时保存。

校验棋盘长度 200、格值 0～7、活动块合法、队列／袋、32 位 RNG、非负安全整数计数、等级／行数一致性、无未消除满行，并核对 4×pieces−10×lines=已占格数。它是结构与局面一致性校验，不是历史重放或防作弊认证。损坏或不兼容局面重建新局，合法最佳保留；存储失败显示提示并仍可游玩。

分享仅为 <code>g=tetris</code> 入口，不替换接收者本机局面。旧游戏存档、旧分享、AppID 与私有工具设置保留；回滚旧代码只缺少新入口。
