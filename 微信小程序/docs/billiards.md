# 台球俱乐部：中式 8 球与斯诺克

## 操作与范围

新增独立台球入口，两种玩法均为**本机轮流双人**，一个人也可以练习。不含联网匹配或电脑对手。轻触/拖动台面瞄准，拖动力度条改变出杆力量，点击母球击点盘选择左右塞和高低杆，再按“击球”。辅助线开关独立，不影响物理；只显示母球首段行进至第一次碰撞的位置，不是保证进球的预测器。球运动时锁定下一杆操作。

使用二维俯视，横竖屏自适应。母球侧塞实际改变碰库后的切向速度；高低杆实际改变母球撞击目标球后的跟进/回拉。不是装饰性击点。物理采用 1/240 秒固定子步、等质量球碰撞、碰库能量损失及台布阻力。满力在一步内移动量小于球径，袋口先检测落袋再处理库边。

这是便于手机游玩的**休闲简化模拟**，不模拟完整滑动到滚动状态转换、旋转传递、弧线球、跳球、偏移、球杆仰角、真实袋角弹性或职业级台布差异；两种玩法共用球台比例和袋口几何。不要据此练习真实赛事的精确走位。

## 规则

中式 8 球：开球后不立即分组，后续合法进球分全色/花色；先击中本组球，清完后才击打黑 8。无进球时须碰库。过早进黑 8、同杆最后本组球和黑 8 进袋、黑 8 杆犯规均判负。开球进黑 8 则复位，不直接胜负。休闲版省略严格开球四球触库及过线判定；犯规统一对手全台自由球（正式开球犯规处理不同）。无需指袋。

斯诺克：15 红球，各 1 分，彩球为黄2/绿3/棕4/蓝5/粉6/黑7。红彩交替，彩球阶段可在界面指定彩球，彩球按阶段复位；最后一颗红球后仍有一次任选彩球，然后按黄到黑清彩。错球、白球入袋等罚分取相关球最高分，最低 4 分。只有白球落袋后给 D 区手中球，普通犯规并非全台自由球。最后黑球同分重新摆黑决胜。省略自由球、foul and a miss 重摆、让对手重打、裁判裁定与比赛时钟；彩球原点被占时使用确定性的安全空位搜索，不等同完整赛事占点规则。

## 调研依据（阅读于 2026-11-13）

- WPA [Rules of Heyball，2025-08-16](https://wpapool.com/wp-content/uploads/2025/08/250816-Rules-of-Heyball.pdf)：中式台球规则依据，特别是开球不分组、黑 8 开球复位和无需指袋。实现与正式规则的差异见上。
- WPBSA [Rules of the Game](https://www.wpbsa.com/rules/)：斯诺克官方规则入口，红彩顺序、罚分、手中球及终局依据。
- Evan Kiefl [Pooltool theory](https://ekiefl.github.io/2020/04/24/pooltool-theory/) 与 [simulation algorithm](https://ekiefl.github.io/2020/12/20/pooltool-alg/)：球状态、旋转、碰撞与离散/事件仿真区别。未引入第三方物理库或复制其代码。
- Dr. Dave [Spin/speed ratio](https://drdavepoolinfo.com/faq/sidespin/spin-speed-ratio/)：旋转与速度比影响碰库反弹。本实现仅保留可感知的简化影响，不是该理论的完整数值求解。

## 存档与生命周期

只写 `games-between:billiards:save:v1`，不会改动已有八款游戏存档。保存完整已结算局面、辅助线偏好；恢复后暂停，点击继续。运动中暂离再回来可以继续本杆；如果关闭进程重新载入，则恢复**本杆开始前**快照，不保存半完成击球。新局/换玩法需确认；取消保留暂停局面。存储失败显示提示。

## 验证

运行 `npm run check`。新增自动测试覆盖两个摆球阵列、力度、左右塞碰库、高低杆碰撞、进袋、分组、黑 8 胜负、红彩转换、罚分与 D 区摆球、复位与存档、触摸取消、暂停、横竖屏和辅助线开关。原有八款游戏回归和核心来源哈希仍执行。

云端 Node / Canvas 检查不等于微信开发者工具或手机实测。交付保持草稿，不上传微信、不合并主分支。真机验收：

1. 两玩法横竖屏进入、重开确认/取消、返回大厅、后台恢复。
2. 单指瞄准，力度 5% / 100%，左右塞碰库及高低杆正碰对比，辅助线关后仍可看球杆方向。
3. 斯诺克彩球指定、母球落袋后的 D 区摆放，8 球全台自由球避开重叠/袋口。
4. 两人轮流完成一局；故意错球、早进黑 8、空杆，确认轮次和罚分。
5. 运动中杀进程，确认回到本杆前；原有黄金矿工/扫雷等存档仍正常。
