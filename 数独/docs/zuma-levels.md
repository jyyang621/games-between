# Zuma 关卡与无尽模式

Zuma 的菜单可切换闯关与无尽，并选择简单、中等、困难、地狱四档。每档分别保存两种模式的局面、最佳成绩和解锁进度，切换不会覆盖另一档的游戏。默认中等，旧版单关和双模式存档迁移到中等档，保留球链、飞行球、连锁和弹药随机状态。返回大厅、切后台、进入菜单和打开玩法说明都会暂停。

## 四档难度

| 难度 | 球速倍率 | 球数倍率 | 第一关球数 | 第一关初速 | 无尽速度上限 | 无尽单波球数上限 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 简单 | 1.6 | 0.8 | 62 | 41.6 | 76.8 | 101 |
| 中等 | 2.2 | 1 | 78 | 57.2 | 105.6 | 126 |
| 困难 | 3 | 1.15 | 90 | 78 | 140 | 145 |
| 地狱 | 4.2 | 1.3 | 101 | 109.2 | 192 | 164 |

倍率以最初未分档的关卡为基准；相对于初次四档版本，球速分别提高到 2、2.2、2.5、3 倍。球数四舍五入为整数；球速倍率同时作用于关卡初速、加速度和速度上限，无尽额外受表内硬上限约束。难度只能在选关/模式菜单切换，继续保存的旅程会使用该局原来的难度；分享入口也携带所选难度。旧局面的已知速度参数会升级到新版，保留球链、得分与弹药。

## 无尽的难度控制

无尽由可持续推进的有限波次组成，每波轮换六条轨道，每次新挑战重新生成随机种子；同一存档恢复后仍保持原轨道和弹药序列。

- 中等档波数为 `w` 时，初速为 `2.2 × (27 + 13 × (1 - exp(-(w - 1) / 12)))`，渐近 88；其他档位使用各自的速度倍率。
- 每波按有效游玩时间增加速度，中等每秒增加 0.22，单波速度最多再增加 17.6；所有档位都受对应的无尽速度上限约束。
- 中等每波球数从 78 渐增，最多 126；其他档位按球数倍率调整。波数增加不会生成无限球链或累计轨道数组。
- 领先球走到轨道 78% 后，前进速度开始平滑降低；到 95% 时，最多降低 42%。界面显示实际前进速度与缓速状态。拉回断链的速度保持原规则，避免削弱连锁救场。
- 清空一波后停在结算页，点击才开始下一波。得分累计一次，刷新、继续或反复保存不会重复计分。失败后重开从第一波开始，最佳分数和最高完成波次保留。

这使难度逐渐提高，但后期不会因波数增长而无限加速。是否通关仍取决于瞄准、换球与连消。

## 稀有万能彩球

所有难度的发射筒和下一球预览都可能出现彩虹球，命中后自动按相邻可接触的颜色参与三消。遇到两种邻色时，优先选择能连接最多弹珠的颜色；不足三颗时会转成普通邻色留在球链上。彩球不隔着空隙消除，也不会变成球链中的第五种颜色。

补充弹药时，至少间隔八颗普通弹药后才会进行 4% 概率抽取；生成彩球后重新计间隔，因此实际长期出现比例低于 4%，不会连续出现。开局前两颗仍为普通弹药。换球只交换现有两颗，不能刷新抽取；彩球、飞行状态、随机进度和间隔计数都随存档恢复。

换球按钮直接展示当前球和下一颗球，竖屏点击高度为 44 像素；暂停或等待开始时也可以交换，不会启动计时。两颗同色时提示“前后同色”，并说明发射后会补充新球；不同色时显示“已换球”。点击只交换一次，并取消未完成的瞄准手势，避免松手误射。

## 维护与检查

`src/games/zuma/levels.js` 定义关卡轨道、配色和难度；`session.js` 管理四档各自的解锁、波次与闯关/无尽存档；`state.js` 管理单局快照；`controller.js` 管理输入与生命周期；`renderer.js` 绘制菜单、缩略图、彩球和速度提示。以上路径相对于同级 [微信小程序工程](../../微信小程序/README.md)，最终位于 `D:\怀旧小游戏\微信小程序`。

核心由 `vendor/zuma/model.ts` 生成，变更规则后按该目录 README 重新生成并校验哈希；不要只改生成文件。原始源码另存于 `vendor/zuma/original/`，旁边的原 Zuma 项目不受影响。

以下命令在 `D:\怀旧小游戏\数独` 中运行：

```sh
node scripts/build-minigame.mjs --check
node --test tests/minigame-zuma*.test.mjs
node scripts/build-minigame-preview.mjs
```

自动测试覆盖轨道差异、四档参数、渐进提速与上限、危险缓速、彩球规则与稀有频率、固定步长一致性、旧存档迁移、难度及模式独立恢复、逐关解锁、计分去重及触控。确定性游玩烟测使用合法的换球、瞄准和发射操作，发射间隔至少 0.35 秒，检查四档的六关及无尽第 1、12、60、1,000,000 波在 420 秒内可清空；它验证这些配置的可玩性，不保证所有随机种子或所有打法都可获胜。
