# 俄罗斯方块规则、接入与验收

本地实现基准 `BL-2026-11-07-03`，日期 2026-11-07（Asia/Shanghai）。规则、控制器、布局与接入已完成，本地全量 640 项测试及构建检查通过；具体平台验收边界见下文。工作区尚未提交，不把旧 HEAD 当作本阶段完整实现。

## 计划与入口

俄罗斯方块作为合集第七款游戏，以稳定 ID `tetris` 注册。大厅每页三款，新增游戏自然出现在第三页。通过统一工厂和游戏契约接入，规则、操作、渲染及存档位于 `微信小程序/src/games/tetris/`；宿主和平台不增加游戏专属模型。

首版为单人无尽玩法。提供七种方块、左右移动、顺时针旋转、软降、直落、下三个方块预览、落点影子、消行计分、等级加速、本机最佳成绩、暂停、重开与续局。暂未实现暂存方块、键盘控制、对战、云存档、排行榜或完整竞技规则。

## 棋盘与算法约定

| 参数 | 约定 |
| --- | --- |
| 可见棋盘 | 10 列 × 20 行 |
| 生成空间 | 顶部允许两行隐藏区域 |
| 方块 | I、O、T、S、Z、J、L，共七种 |
| 出块 | 带确定性随机状态的七袋洗牌；每袋各出现一次 |
| 旋转 | 普通墙踢；不是完整 SRS |
| 消行分数 | 单次 1／2／3／4 行为 100／300／500／800 × 锁定前等级 |
| 软降分数 | 玩家主动向下移动成功，每格 1 分 |
| 直落分数 | 每格 2 分，立即锁定 |
| 等级 | 每累计消除 10 行升一级，上限 20 |
| 自动下落间隔 | `max(80, round(800 × 0.82^(等级−1)))` 毫秒；1 级 800ms，最快 80ms |
| 落锁延迟 | 触地后 500ms |
| 落锁重置 | 同一块触地后成功左右移动或旋转，最多重置 15 次；空中移动不消耗次数 |
| 长帧补偿 | 单次 tick 计入最多 100ms，避免后台恢复补算整段时间 |
| 顶出 | 锁定时仍有格子位于可见棋盘上方则结束；下一块无法出生也结束 |

棋盘使用长度为 200 的整数数组；活动方块保存类型、旋转、坐标，队列及 RNG 状态随局面保存。纯引擎负责碰撞、移动、旋转、直落距离、锁定、清行、计分、出块与快照校验；控制器通过宿主 tick 管理速度和落锁时序。

使用 Mulberry32 伪随机状态和 Fisher–Yates 七袋洗牌；内部队列保留 5 块，界面展示前 3 块，袋余量为 0～6 块。普通墙／地面踢位依次尝试 `(0,0)、(-1,0)、(1,0)、(-2,0)、(2,0)、(0,-1)、(-1,-1)、(1,-1)、(0,-2)`；O 块旋转视为无变化。生成锚点为 `y=-1`，隐藏区域碰撞限制最低到 `y=-2`；不是完整 SRS。所有加分在 `Number.MAX_SAFE_INTEGER` 饱和，避免极值存档加分溢出成非法整数。

## 操作与生命周期约定

触屏按钮提供向左、向右、旋转、“软降”和“直落”。软降每次下移一格；直落立即锁定。棋盘上左右滑动移动、下滑逐格下降、轻点顺时针旋转。移动阈值为一格宽度与 12 逻辑像素的较大值，每次手势事件最多左右 10 格／下移 20 格；额外触点取消当前手势，不把上滑当成旋转。显示三个后续方块及幽灵落点，帮助玩家判断位置。

页面保留大厅、分享、玩法、暂停和重开入口；进行中的局面重开须确认并保留最佳成绩，取消后保留原局且暂停。暂停、后台、返回大厅、分享和旋屏不推进掉落或落锁；恢复后手动继续。音乐使用宿主共享播放器，仅未暂停的进行中局面报告 `musicActive=true`。

布局目标覆盖 390×844、320×568、844×390、480×320，预留安全区及宿主音乐／原生胶囊保留区域；短屏与横屏实际可读性、误触仍需独立验证。

## 数据、兼容与迁移约定

独立存档键为 `games-between:tetris:save:v1`，外层版本为 1，保存当前局面及本机最佳，以及 `timing.fallMs / lockMs / lockResets`（下落累计、落锁累计、当前块落锁重置次数）。控制器每累计 1 秒有效游戏时间保存，并在落锁、暂停、重开、有效手势结束及宿主 save 时保存。计时字段按各自合法范围恢复，非法计时回退为 0；恢复不会白送新一轮 15 次调整。

局面由引擎严格验证棋盘长度 200、格子 0～7、合法活动块、5 块队列、袋尾不重复、32 位 RNG 状态、非负安全整数计数和等级／行数一致性；保存时不能存在未清理满行。另核对 `4×已锁定块数−10×消行数=棋盘已占格数`，拒绝不一致快照。损坏或不兼容局面安全回退新局，合法最佳成绩可保留。可恢复的未结束局面以暂停状态打开。这是结构与局面一致性校验，不是历史重放或防作弊认证。

已有游戏的存档键、旧分享和私有开发工具设置保持原样。俄罗斯方块分享参数为 `g=tetris`，仅定位入口，不能替换接收者本机局面。回滚到旧代码会失去入口，旧游戏仍不读取这个独立槽。

规则采用直接维护的 CommonJS JavaScript，不增加 vendor 或独立生成核心。微信入口与浏览器预览仍由现有依赖图脚本生成；原核心和音乐来源检查通过。
