# 黄金矿工 TNT 布置与爆炸范围

TNT 用于局部矿群中的风险取舍。前 20 关保留原矿场，21–40 关和无尽矿场将少量桶放在部分黄金、钻石之间。桶不再孤立堆在底部两角，也不排列成拦住整片矿区的墙。玩家可以先取周围宝藏，再决定是否引爆桶清理附近物件。

## 范围与收入

`BARREL_BLAST_RADIUS` 为原始 1280 × 720 矿场中的 140 像素。红色虚线和淡色区域提示范围，瞄准桶时加强提示；横竖屏按矿区坐标比例显示相应椭圆。物件边缘进入波及范围也可能被炸毁。

抓钩碰桶或精灵挖到桶会触发爆炸。范围内尚未钩住的黄金、钻石、石头、钱袋、移动物件会被摧毁，邻近桶会连锁；每个桶只爆炸一次。炸毁物件没有收入，抓钩空钩收回后可以继续下钩；已经钩住并在回收中的物件得到保留。随身炸药仍是另一种道具，用来炸掉自己钩中的物件。

## 通道与余量

每张含桶矿场只布置 1–2 桶，桶在矿群间留有物理间隙，中央与两侧保留取矿方向。可达性检查使用实际抓钩射线，覆盖单人、双人、横屏和竖屏，确认各抓钩都有可取的金钻。

布置还检查所有桶引爆后剩余安全静态金钻的总价值不少于关卡目标。这提供目标收入余量；实际通关仍取决于瞄准、收矿顺序和时间管理。无尽高层数保持物件数量有界，不因层数增加而堆成桶墙。

## 维护与验证

维护源位于同级 [微信小程序工程](../../微信小程序/README.md) 的 `vendor/gold-miner/{levels,engine,renderer}.ts`；`original/` 保留原始代码，不修改旁边的原黄金矿工项目。运行核心位于该工程的 `src/games/gold-miner/core/`，由生成器转译。来源清单同时记录原始副本、维护源和生成产物的哈希。以下命令在 `D:\怀旧小游戏\数独` 中运行：

```sh
node ../微信小程序/vendor/gold-miner/generate.mjs --typescript D:/黄金矿工/node_modules/typescript/lib/typescript.js
node scripts/build-minigame.mjs --check
node --test tests/minigame-gold-miner*.test.mjs
node scripts/build-minigame-preview.mjs
```

回归覆盖矿图种子确定性、桶与金钻的距离、可达射线、爆后价值余量、爆炸边界、连锁去重、移动物件的引爆时刻位置、双钩已持物保护和横竖屏范围一致性。浏览器预览检查画面与交互，手机微信的触控和显示仍需真机验收。
