# 游戏之间

一个以微信小游戏大厅为入口的休闲游戏项目：首页名称为「花自飘零的游戏空间」，数独、黄金矿工、Zuma、经典 2048 和扫雷均可进入游玩。最终工作目录为 `D:\怀旧小游戏`，本说明位于其中的 `数独/`；微信工程在同级的 `微信小程序/`，已配置 AppID `wxdf7e7953e1db2558`，**尚未上传、审核或正式发布到微信**。

需要 Node.js 20 或更新版本。以下直接调用脚本的命令均在 `D:\怀旧小游戏\数独` 中运行；外层目录保留 Git 历史和 npm 代理入口。目录职责及工具迁移步骤见 [目录布局说明](docs/directory-layout.md)。

```sh
node scripts/build-minigame.mjs
node scripts/build-minigame.mjs --check
node --test tests/*.test.mjs
```

随后用微信开发者工具导入 `D:\怀旧小游戏\微信小程序`，项目类型为小游戏。完整导入、真机预览和发布步骤见 [微信小游戏说明](../微信小程序/README.md)。[架构与新游戏接入](docs/architecture.md) 说明目录分层、模块接口与扩展方式。

小游戏采用通用宿主和独立游戏模块：`src/app/` 管理导航与生命周期，`src/platform/` 适配微信能力，`src/hub/` 绘制大厅，所有游戏都在 `src/games/<id>/`。`src/registry.js` 是游戏元信息与工厂的唯一注册入口；新增游戏只需实现模块并注册，宿主、大厅和预览构建自动识别。

微信小游戏中的数独支持可解释提示和只读答案对照：填错时可确认纠正一格，正常逻辑步骤先解释、点击「应用提示」后应用，候选排除会给出反馈和高亮。「显示答案」首次查看先确认，返回保留原棋盘与笔记，查看期间暂停计时和配乐；看过答案的本局完成不计普通或实战成绩，撤销与恢复不会清掉查看标记。详见 [数独提示、答案及评级说明](docs/sudoku-rating.md)。

黄金矿工复用原项目的 40 关、无尽、单人/合作/对战、道具商店与移动物件；Zuma 提供六个不同轨道的闯关关卡和无尽模式，保留射击插球、换球、断链合拢与连锁。球速随游玩时间渐进提升；无尽模式采用有速度上限的连续波次，接近终点自动缓速，每波结束可休息后继续。两款游戏改为 Canvas 触控界面，使用各自的本地存档，返回大厅或切到后台时自动暂停。原网页项目继续保留。关卡参数与无尽平衡说明见 [Zuma 关卡设计](docs/zuma-levels.md)。

五个小游戏共用用户提供的《平沙落雁》和《阳关三叠》两首配乐，默认开启，游戏运行时依次轮播，第二首结束后回到第一首；顶部微信胶囊左侧的音乐按钮可随时开关，设置保存在本机。大厅、暂停、结算、后台和原生弹窗期间停止播放，恢复游戏后接着播放，切换游戏不会叠音。原文件保留在外层 `音频/`，微信工程使用转码后的 MP3 运行副本。当前尚无操作音效。浏览器预览也可播放，首次可能需要点击页面；微信开发者工具和手机的实际音量、切曲衔接仍待验收。素材来源、播放边界和维护方法见 [背景音乐说明](docs/background-music.md)。

## 小游戏本地浏览器预览

Zuma 还可选择简单、中等、困难、地狱四档，按球速和球数区分；每档保存独立进度。发射筒偶尔补入万能彩球，按相邻颜色参与三消，补充之间至少间隔八颗普通弹药。

先完成上面的构建，再生成浏览器预览并启动本地服务器：

```sh
node scripts/build-minigame-preview.mjs
node scripts/serve.mjs
```

打开 [http://127.0.0.1:4173/preview/](http://127.0.0.1:4173/preview/)，检查大厅分页进入五个游戏、返回和继续、暂停恢复及刷新后存档。黄金矿工检查六种模式、下钩/炸药和商店；Zuma 在轨道区域按住拖动瞄准，松手发射，用换球按钮切换颜色；2048 在大厅第二页，滑动棋盘或点击方向按钮合并数字；同页的扫雷通过「翻开」「插旗」按钮切换点击模式。修改小游戏源码后，需要重新运行预览生成命令并刷新页面；数独引擎源码有变更时也要先重新构建小游戏。

2048 使用经典 4×4 规则，只有有效移动才随机生成 2 或 4；合并数字计入得分，合成 2048 后可以继续挑战。当前棋盘与最佳成绩自动保存在本机，重新打开或返回后手动继续；玩法、算法及存档边界见 [2048 设计说明](docs/2048.md)。

扫雷提供初级 9 列×9 行／10 雷、中级 9 列×12 行／20 雷和高级 12 列×16 行／40 雷。首次翻开的格子及相邻一圈无雷，空白区域自动展开；可插旗，再在「翻开」模式点数字快速排查相邻格，插错旗仍可能触雷。普通随机棋盘可能需要猜测。各难度分别保存最佳用时，但仅保留一个当前棋盘，进行中的重开或换难度需要确认；返回、后台和刷新恢复后手动继续。详见 [扫雷规则、算法与存档](docs/minesweeper.md)。

该预览将同一套小游戏模块配合 `preview/wx-preview.js` 使用；适配层在浏览器中模拟 `wx` 的 Canvas、存档、弹窗、分享与前后台事件。它适合本地画面和交互 QA，**不是真机验证**；本地分享链接也不能作为正式微信小游戏入口。正式预览、分享和平台兼容性仍需用微信开发者工具及手机微信检查。停止本地服务器按 `Ctrl+C`。

## 数独之间 · 网页版

一个可以分享给朋友的中文数独网站，采用原生 HTML、CSS 和 JavaScript，适配电脑和手机，无需构建或安装依赖。

- 多档难度与每日挑战。
- 数字输入、候选笔记、撤销、擦除、冲突检测和提示。
- 点击棋盘下方「填全笔记」，一键按当前行、列、宫格填入所有空格的候选数字；可整步撤销，也会自动保存。重新点击会按当前棋盘重算全部笔记。
- 暂停计时、键盘操作、偏好设置与本机游戏记录。
- 自动保存本机进度，随时回来继续玩。
- 通过链接邀请朋友挑战同一道题。

## 网页版本地运行

需要 Node.js 20 或更新版本。在本目录 `数独/` 或外层仓库目录运行：

```sh
npm start
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。开发服务器仅监听本机；端口被占用时可通过 `PORT` 环境变量指定其他端口。

```sh
npm test
```

游戏逻辑测试使用 Node.js 自带测试工具。

也可以不使用 npm，直接运行 `node scripts/serve.mjs` 和 `node --test tests/*.test.mjs`。完整测试同时覆盖网页数独引擎与微信小游戏的状态、控制器和平台适配逻辑。

## 网页版发布到 GitHub Pages

1. 将代码上传到 GitHub 仓库 `jyyang621/sudoku` 的 `main` 分支。
2. 打开仓库 **Settings → Pages → Build and deployment**，将 **Source** 设为 **GitHub Actions**。
3. 在 **Actions** 中运行 **Deploy Sudoku to GitHub Pages**，也可以推送一次提交触发部署。
4. 部署完成后，以 GitHub Pages 页面显示的访问地址为准。该仓库的预期地址是 [https://jyyang621.github.io/sudoku/](https://jyyang621.github.io/sudoku/)。

以后更新 `main` 分支会自动运行测试并重新发布。工作流从 `数独/` 读取网页版页面及 `js` 文件，再按原来的站点根目录布局发布，因此现有线上地址及同题链接无需因本次目录整理而变化。部署不包含本地脚本、测试、同级 `微信小程序/` 和 `preview/`；微信小游戏需要单独通过微信平台上传发布。

部署设置参考 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 文件

- `index.html`：页面结构。
- `styles.css`：响应式样式。
- `js/app.js`：交互、存档与分享。
- `js/sudoku.js`：题目生成与数独逻辑。
- `scripts/serve.mjs`：无依赖本地服务器。
- `scripts/build-minigame.mjs`：微信小游戏通用构建与接口检查，自动发现 `scripts/games/` 的游戏构建/校验钩子。
- `scripts/games/`：游戏各自的生成与规则校验，数独仍以 `js/sudoku.js` 为算法源。
- `scripts/build-minigame-preview.mjs`：生成本地浏览器预览包。
- `preview/`：以浏览器 `wx` 适配层预览小游戏，用于本地 QA。
- `../微信小程序/src/app/`、`platform/`、`hub/`：通用宿主、平台边界与可分页大厅。
- `../微信小程序/src/games/`：数独、黄金矿工、Zuma、2048 和扫雷的独立模块，各自拥有状态、渲染及规则核心。
- `docs/minesweeper.md`：扫雷难度、首步安全、规则算法、存档验证及验收记录。
- `docs/architecture.md`：模块契约、依赖约定与新游戏接入示例。
- `../.github/workflows/pages.yml`：GitHub Pages 自动部署。
- `docs/directory-layout.md`：外层仓库、两个工作目录、工具导入和迁移验收说明。

网页数独参考 [Sudoku Kingdom](https://www.sudokukingdom.com/zh/) 的玩法，自行实现页面与游戏逻辑。每道生成题都经过唯一解验证；难度按已知数字数量分级。网页存档保存在当前浏览器中，不会跨设备同步。
