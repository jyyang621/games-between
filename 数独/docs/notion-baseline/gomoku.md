所属项目：<mention url="https://app.notion.com/p/3fd90dbc56c3804385eec17277837dec">微信小程序——怀旧小游戏</mention>。阶段基准 <b>BL-2026-11-07-02</b>，日期 <date start="2026-11-07" />，时区 Asia/Shanghai。

## 项目计划与当前状态

用户确认加入“人机对战＋同机双人”。五子棋已作为第六款游戏接入大厅第二页，与 2048、扫雷同页。当前状态为本地实现和自动检查通过，微信开发者工具已完成部分真实交互验收；手机真机、上传、审核与发布未执行。

本阶段按用户新增要求提供简单、普通、困难三档本地电脑，默认普通；同时解释三档选点与搜索实现。联网房间、排行榜和专业棋力等级未实现，未安排扩展承诺。

## 当前实现

- 15×15 交叉点棋盘，黑先、交替落子；横、竖、两条斜向任意连续五子及以上获胜，无禁手。满盘且无人获胜判和，终局禁止继续落子。
- 人机默认玩家执黑；“换先后”支持玩家执白、电脑先行。人机模式旁显示“简单难度／普通难度／困难难度”，点击打开原生三档菜单，默认普通。同机双人隐藏难度入口，由两位玩家在同一设备轮流操作。
- 双人悔棋撤回一手。人机撤回最近一次玩家落子及之后电脑应手；电脑尚未应手时只撤回玩家一手；玩家执白时不能撤回电脑唯一开局落子。终局也可悔棋。
- 最近一手有标记，获胜连线高亮；电脑回合和暂停时禁止玩家落子。
- 暂停、返回大厅、后台、分享和旋屏遵循统一宿主生命周期，回来需手动继续。非空进行中棋盘重开、换模式、换先后或换难度前确认，取消保留棋局。仅取消难度菜单或选原难度会恢复此前对局；取消换局确认后保持暂停，可手动继续。
- 沿用共享背景音乐与开关；暂停、终局和后台停止音乐推进，不新增播放器。

## 规则、算法与参数

棋盘用 225 项数组表示，0/1/2 分别为空/黑/白；棋谱为交叉点索引。每次落子沿四个方向扫描两端，分别检查行列边界，避免跨行相连。悔棋重放保留棋谱，重建轮次与胜负。

电脑由本地 JavaScript 棋类算法实现，无模型 API、联网推理或远端服务。三档均在已有棋子周围两格列候选、空盘选中心，并先寻找己方一步成五，再阻挡对方一步成五；计算不修改真实棋局。

| 难度 | 决策方式 |
| --- | --- |
| 简单 easy | 连续棋子数量与两端开放程度浅层评分；从前 3 个且不低于最高分 72% 的候选中按棋谱哈希选点，带有可复现变化 |
| 普通 normal | 保留原版四方向五格窗口、活四、活三及复合威胁评分；进攻分＋防守分×1.08，轻微偏向中心 |
| 困难 hard | 在普通棋形评分上进行 negamax / alpha-beta 搜索，最多 3 手，即电脑→玩家→电脑 |

困难档普通候选分层上限为 <b>10／8／6</b>，节点预算 <b>600</b>。一步成五和必须防守的点单独识别，避免被普通排序截断；己方不能直接获胜且对方存在两个不同成五点时，识别为一步无法防住的双杀。试算只更新四方向前后 4 格内受影响的评分，并在撤回时恢复缓存，减少重复计算。

简单档的变化由棋谱决定，重开相同存档不会随机换应手。三档仍是有界局部算法，困难也不穷举全盘或保证获胜，可能漏掉更长组合和候选之外的招法；样本战术通过不等于所有棋局或玩家体验。手机性能和实际难度体验仍需验证。

控制器使用宿主 tick 累计 <b>320ms</b> 后同步计算一手，无独立长期定时器；暂停和后台不计算，恢复不补下多手。320ms 是轮次展示延迟，不是手机计算性能保证。

## 存档、迁移与分享

稳定注册 ID 为 <code>gomoku</code>，入口分享为 <code>g=gomoku</code>，不复制发送者棋谱。独立存档键为 <code>games-between:gomoku:save:v1</code>，结构为 <code>{ version: 1, round }</code>，保存模式、玩家颜色、<code>difficulty</code>、棋谱与完整局面。版本和键保持不变：旧存档缺少 <code>difficulty</code> 时补为 <code>normal</code>，显式未知难度视为损坏。难度随悔棋、重开、换先后和模式切换保留，同机双人不使用电脑难度；入口分享不强行更改接收者难度。

合法落子、悔棋和换局即时保存，宿主在生命周期节点另行保存。恢复从空盘逐手重放，核对棋盘、轮次、终局、获胜者与连线，拒绝重复、越界、终局后继续落子、不一致状态与不支持版本。合法未结束局恢复为暂停；损坏存档回退为新人机局。读写失败仍可游玩，界面显示存档不可用。

现有游戏键、旧分享与私有工程设置保留，无跨游戏迁移；回滚到旧代码时无法进入五子棋，但旧游戏数据不受影响。
