## 项目计划书：目标、范围与验收
### 产品目标
- 一次点击从大厅进入，初次打开可选模式与难度；有进度时可继续原旅程。
- 六关有不同轨道、主题和逐步提高的压力；清关后手动进入下一关，已解锁关卡可重玩。
- 简单、中等、困难、地狱以球速和球数区分，默认中等，每档独立保存。
- 无尽按有限波次持续推进，轮换六条轨道，球速和数量有上限，接近终点时缓速，波间允许休息。
- 稀有彩球能够作为任意邻接颜色使用，但不能通过换球反复刷新概率。
- 瞄准、发射、换球、暂停、返回大厅和存档应在横竖屏及生命周期切换中保持一致。
### 当前范围
已实现：本地单人、六关、四档难度、双模式、普通四色球、稀有万能彩球、下一球预览、同色说明与换球反馈、连锁计分、速度条及危险缓速提示、菜单与帮助、横竖屏适配、本地存档迁移、分享参数、原始 MIT 来源保留。
当前未实现：联网对战、云端同步、排行榜、广告与支付、关卡编辑器、输入录像与回放、射击/消除等操作音效。已接入宿主共享的可开关原创背景音乐，具体门控见本页背景音乐阶段；模型仍没有 Phaser、DOM 或浏览器依赖。

## 六关与四档参数
### 参数的两个层次
`CAMPAIGN_LEVELS` 保存未分档的原始设计基线，即使对象的 `difficulty` 字段写为 `normal`，其中数值仍未乘中等倍率。正式游戏通过 `getCampaignLevel(index, difficulty)` 获取缩放后的配置。不得将下表基线 26～41 的初速误记为当前默认中等的实际初速。
速度单位为世界像素/秒，加速度单位为世界像素/秒²；世界固定为 1120 × 700。屏幕显示按缩放比例换算，不同手机像素密度不会改变物理速度。

### 局内提速
名义前进速度为 `min(maxSpeed, speed + acceleration × elapsed)`，`elapsed` 只在实际物理步骤中增加。暂停、菜单、帮助或后台不增长，因此不会在返回游戏时突然补算离线加速。闯关不使用危险缓速；无尽在此名义速度上再乘危险区域系数。
## 无尽模式的生成与难度边界
无尽是一组连续的有限波次，每波都有明确的 `totalBalls`；清空后停留结算页，玩家点击下一波才开始。无尽的长期可玩性由「渐近增长、有上限、临终点缓速、波间休息」共同控制，不依赖无限增加球速。
定义 `w = clamp(floor(输入波数), 1, Number.MAX_SAFE_INTEGER)`；非有限波数回落第 1 波。`p = 1 - exp(-(w - 1) / 12)`，档位速度倍率为 `m`，球数倍率为 `b`，无尽硬速度上限为 `C`。
```plain text
轨道序号 = (w - 1) mod 6
本波初速 = (27 + 13 × p) × m
本波速度上限 = min(C, min(48, 27 + 13 × p + 8) × m)
本波加速度 = 0.10 × m
本波球数 = round(min(126, 78 + floor(48 × p)) × b)
```
中等初速从 59.4 渐近 88，单波上限不超过 105.6；地狱初速从 113.4 渐近 168，额外受 192 的硬上限约束。公式在极大波次下仍以常数次运算生成一个配置，不按波数分配数组；球链只属于当前波。
每次新的无尽挑战产生会话种子；同一挑战的各波将会话种子和波数混合为本波种子。混合使用 32 位异或和 `Math.imul`，并纳入大于 2³² 的波数高位，避免大整数浮点乘法吞掉种子。存档继续使用原种子；重新挑战从第 1 波开始并产生新种子。
### 危险区域缓速
以领先球位置 `head.s / track.length` 表示轨道进度。到 78% 后开始平滑缓速，95% 后达到最大减速；不会改变弹丸速度或断链拉回速度。
```plain text
q = clamp((领先球进度 - 0.78) / 0.17, 0, 1)
smooth = q² × (3 - 2q)
实际前进速度 = 名义速度 × (1 - 0.42 × smooth)
```
最大降低 42%，即保留名义速度的 58%。HUD 使用 `currentSpeed` 显示实际速度，并提示「险境缓速」。这增加反应窗口，但不代表所有打法或种子必定可通关。

随机生成器为 Mulberry32。同一关卡配置、种子和输入序列产生一致结果。球链预生成按色分组：72% 生成两颗，其余生成三颗，下一组避免与上一组同色。正式配置使用四种普通颜色；弹药只从当前可用普通颜色中选择，无球时参考尚未生成的颜色。默认无配置的 `new GameModel()` 仍保留旧版常速 26、78 球、禁用彩球的兼容行为，不代表正式中等难度。
### 固定步长与执行顺序
`step(dt)` 将时间加入累加器，按 1/120 秒循环推进，不把渲染帧率当作游戏规则。控制器对单次前台帧增量封顶 50 毫秒，避免恢复前台或掉帧后大量追赶。等待、暂停和终局状态不推进模拟。
```plain text
每个固定步：
  增加有效游玩时间，减少发射冷却
  记录本步球链运动前位置
  移动球链并处理断链重新接触
  移动弹丸，处理移动目标的扫掠碰撞与插入
  入口有间距且仍有库存时补一颗球
  刷新已经不在可用颜色集合中的普通弹药
  若所有预定球已生成且球链为空：胜利
  否则若任一球达到轨道终点：失败
```
弹丸碰撞与消除先于最终失败判定，因此同一步内的救场发射可先消除终点前球链。未生成的库存尚未耗尽时，即使暂时清空球链也不会提前判胜。
### 轨道：样条、弧长与切线
`Track` 使用 Catmull–Rom 曲线，每对控制点间默认采样 48 份；先建立样本和累计距离表，再用二分查找与线性插值将距离 `s` 映射为空间点。速度按弧长推进，而不是按样条参数推进，减少弯道速度不均。
切线从命中的样本段方向求得；`s` 小于 0 或大于长度时沿端点方向外推，便于入口与出口边界处理。球链按 `s` 升序排列，入口侧是数组开头，领先球是最后一颗。
### 高速与移动球的碰撞
弹丸对每颗球使用相对运动的线段—圆求交：从「弹丸旧位置 − 球旧位置」到「弹丸新位置 − 球新位置」，检测半径为两球半径之和 34 的圆，解二次方程，取 0～1 内最早命中。若起点已在圆内则命中时间为 0。遍历后选最早碰撞，避免高速穿透与隔着前排球命中后排。
每步主要碰撞成本约为弹丸数 × 链上球数，轨道点查询使用二分查找。当前球数由难度和单波边界控制，并非随波数无限增长。
### 插球与三消
命中点相对球心的向量与轨道切线点乘，决定插到命中球的前侧或后侧；近乎垂直/中心命中使用稳定的前侧回退。插入后只向前修正受影响球的间距，保持球心间至少一个直径。
`findConnectedRun` 从新球向两侧扩展，要求同色且物理间距不超过 34.2；空隙两侧即使同色也不视为已连通。连通组至少三颗才消除，直接命中以连锁倍率 1 开始。
### 断链与连锁计分
球链按大于 34.2 的间距划分连续段。入口侧第一段以实际前进速度推进；后续段若空隙两端同色，则以前进方向的反向速度 190 拉回，异色则暂时停住，等待被后链追上。接触后修正距离，按入口到出口的顺序结算。
每次消除记录新空隙两端存活球的 ID 与下一连锁倍率；重新接触仍为同色且形成三颗以上时按该倍率消除。插球、再次消除或邻接关系变化会清理失效的空隙元数据，避免错误继承连锁。
```plain text
本次得分 = 消除颗数 × 10 × 连锁倍率
直接消除倍率 = 1
本次消除留下的空隙，下次成功接触倍率 = 当前倍率 + 1
```
`bestCombo` 记录本局最高连锁倍率；控制器消费 `pop`/`combo` 事件生成粒子与加分文字，特效不影响物理或随机数。
## 稀有万能彩球
颜色 0～3 是普通球，颜色 4 只允许出现在当前弹药、下一球和飞行弹丸中。全部正式闯关与无尽配置启用彩球；开局前两颗弹药仍为普通颜色。
### 生成概率与防刷新
补充弹药时每次只消耗一次随机抽样。普通弹药计数达到 8 后，该次补弹有 4% 机会生成彩球；生成后计数清零。未抽中则将剩余区间重新映射到普通颜色集合，计数封顶为 8。长期出现比例低于 4%，彩球之间至少隔 8 颗普通弹药，不能连续出现。
```plain text
r = 随机数()
若彩球已启用且普通计数 >= 8：
  若 r < 0.04：普通计数 = 0；返回彩球
  否则 r = (r - 0.04) / 0.96
普通计数 = min(8, 普通计数 + 1)
返回可用普通颜色[floor(r × 颜色数量)]
```
换球只交换已有两颗弹药，不抽随机数、不改计数、不重新生成彩球；普通颜色刷新也保留现有彩球。当前/下一球中的彩球、飞行彩球、随机抽取进度和普通计数都会随快照保存。
### 命中后选色
彩球先按命中球颜色插入，再检查命中球、插入后侧邻球、前侧邻球的候选颜色。依次临时赋色并计算物理连通组长度，选择可连接最多颗的颜色。相同长度时优先命中球的颜色，再保留候选遍历的先后顺序。
若能形成三颗则按普通规则消除；不足三颗时转换成普通邻色留在球链，不会留下第五种颜色。彩球不隔着物理空隙合并同色组，也不直接清屏。
## 输入、换球与界面生命周期
竖屏把原始横向世界旋转 90° 绘制，触控通过逆变换映射回世界坐标；横屏直接缩放世界并在侧栏显示控制。布局预留安全区域和微信胶囊下缘。
棋盘点击为抬手发射；拖动更新瞄准，释放后发射。一个手势绑定触点 `identifier`，其他手指结束不触发该手势；取消、暂停、方向变化、离开、进入帮助或切模式都会丢弃未完成手势。棋盘外触点不开始瞄准，冷却内重复发射被模型拒绝。
换球按钮直接展示当前球与下一球；竖屏热区高度 44 像素，横屏侧栏为独立按钮。等待开始、游戏进行中、暂停状态均可换球；胜负终局不可换球。交换两颗不同颜色显示「已换球」，相同颜色显示「前后同色」，并提示发射后补入新球。该动作取消残留瞄准、立即保存，暂停时换球不会启动时间。
打开帮助会暂停；仅当帮助打开前处于正常游玩，且期间没有再发生后台/离开等生命周期暂停，关闭帮助才恢复。重开或新挑战若将替换已有局面，使用宿主确认弹窗；控制器通过 `generation` 校验回调，离开、切模式或切难度后返回的旧确认不能替换新的局面。

## 存档结构、兼容与随机恢复
### 存储键与 v3 结构
仍使用原键 `games-between:zuma:v1` 以找到已安装用户的旧数据；键名中的 v1 不是当前载荷版本。当前载荷 `version: 3`：
```plain text
version: 3
mode: campaign | endless
difficulty: easy | normal | hard | hell
profiles:
  每个难度:
    unlocked: 已解锁的最大零基关卡下标
    campaign: { levelIndex, best, round }
    endless: { wave, seed, totalScore, credited, best, bestWave, round }
```
共四档 × 闯关/无尽八个局面槽。`best` 在闯关是本难度最佳单局分，在无尽是本难度最佳累计分；`bestWave` 是最高已完成波次。切档不会复制其他档位的解锁或成绩。
### 单局快照
保存状态、分数、最高连锁、已生成数、两颗弹药、有效时间、固定步累加器、冷却、下一个实体 ID、随机抽取计数、彩球间隔计数、球链、飞行弹丸及断链连锁映射。快照中的 `playing` 统一保存/恢复为 `paused`，防止打开页面即悄悄继续。
配置身份为有固定字段顺序的 JSON 字符串，绑定种子、总球数、完整轨道控制点、初速、上限、加速度、危险缓速开关和彩球开关。普通换主题文案不影响物理身份；不匹配的物理配置不会强行恢复。
### v1 / v2 与旧速度迁移
- v1 原单关格式 `{ version: 1, best, round }` 进入中等档第一关；不复制到其他难度。无配置身份的旧快照只允许原首关种子 74219、78 球及原轨道。
- v2 双模式格式迁移到中等档的闯关与无尽，保留对应解锁、记录和局面；其他三档从各自初始状态开始。
- v3 保留四档独立槽。此前四档速度分别使用 0.8/1/1.2/1.4 倍，无尽硬上限 38.4/48/56/64。每个当前定义显式携带 `previousMotion`，仅当快照的 `speed`、`maxSpeed`、`acceleration` 三项与已知上一版全部精确相符时，替换为当前三项。
- 升级旧速度时仍须匹配种子、轨道、球数等其余物理身份；任意篡改、只改一部分运动参数、移用其他轨道的局面均拒绝。旧快照缺少彩球开关时补当前开关；缺少彩球间隔时从 0 开始。
- 旧局面、得分、弹药与随机进度保留，后续推进采用新速度公式；保存后配置身份更新，重新载入不会退回旧速度。
### 随机恢复与数据边界
创建模型会按种子重建相同预生成球序列；随后按快照记录的构造后随机抽取次数推进生成器，而不是保存无上限输入录像。重开重新播种，同一关初始弹药一致。快照还保存飞行彩球和断链倍率，避免继续时改变未来弹药或重复发放奖励。
验证器拒绝非有限坐标、重复 ID、球序逆序、无效邻接连锁、越界分数/波数等。主要边界包括：输入字符串不超过 1,000,000 字符；单局分数 ≤ 10⁹；有效时间 ≤ 86400 秒；随机抽取 ≤ 100000；球链 ≤ 256、弹丸 ≤ 128、断链条目 ≤ 256；ID 在受限整数范围内。胜利快照必须没有球链且已生成全部预定球。
已记账的无尽快照还须保留合法的胜利终局，累计分不少于本波分且最高完成波数覆盖本波，避免坏快照把分数转入下一波或重复结算。损坏局面只重置对应槽，合法记录和其他槽尽量保留。存储失败返回失败状态但不使游戏进程崩溃；本地数据仍可能被平台或用户清理，当前没有云端备份。
## 分享入口
当前分享 query 形如 `g=zuma&m=campaign&difficulty=normal&l=1`，无尽为 `g=zuma&m=endless&difficulty=normal`。标题包含模式和难度。
`m` 仅接受 `campaign`/`endless`，`difficulty` 仅接受四档 ID，`l` 为 1～6 的关卡预览编号。分享进入模式/难度菜单，不重置另一槽，不直接开始，不绕过解锁；老分享仅 `g=zuma` 仍可进入当前保存状态。
