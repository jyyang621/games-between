## 目标与入口

新增经典“曹操脱困”滑块玩法，稳定 ID `huarongdao`，作为合集第八款接入大厅第三页，与俄罗斯方块同页。默认进入“入门”；通过注册表惰性工厂接入，保持 app/platform/hub/registry/games 边界，宿主不保存华容道专属模型。

首版为三个固定开局的本地单人解谜，不随机出题，不提供实时提示或自动解题。名称“入门／进阶”是本项目练习标签，不代表经过玩家测试的难度评级。

## 规则与固定开局

| 项目 | 当前实现 |
| --- | --- |
| 棋盘 | 4 列 × 5 行，始终留两格空位 |
| 棋块 | 曹操2×2、关羽2×1、张飞／赵云／马超／黄忠各1×2、四兵各1×1，共10块 |
| 移动 | 只能四向平移，不能旋转、重叠、穿过其他块或越界 |
| 计步 | 每成功移动1格计1步；一次拖动两格计2步 |
| 胜利 | 曹操左上角到达 x=1、y=3，即棋盘内下方中央出口，不另计拖出画面 |
| 撤销 | 回退最近一次1格移动；通关后也可悔一步，原最佳不撤销 |
| 步数上限 | 当前保留的移动历史最多10000步；达到上限可悔棋或重开 |

| 关卡ID | 名称 | 来源 | 独立BFS最短单位格步数 | 展开等价状态 |
| --- | --- | --- | ---: | ---: |
| `beginner` | 入门 | 经典解路径完成第104步后的局面 | 12 | 94 |
| `intermediate` | 进阶 | 经典解路径完成第76步后的局面 | 40 | 2065 |
| `classic` | 经典·横刀立马 | 传统横刀立马几何布局 | 116 | 24026 |

原创离线广度优先搜索将每次正交移动一格视为等权边，只在去重键中合并相同尺寸的非曹操块，实际路径保留棋块ID。前两关取经典最短116步路径的中／末段状态后，再从各自初盘独立BFS求解；三条解路径逐步交给运行引擎重放，确认合法、终局正确且快照可恢复。因此最短结论仅适用于这三个固定布局和本项目“每格一步、到达出口不额外出界”的计步规则，不能与其他计步口径直接比较。

证据为 `数独/artifacts/huarongdao/solutions.json`，测试路径为 `数独/tests/fixtures/huarongdao-solutions.json`，复现脚本为 `数独/artifacts/huarongdao/solve-levels.mjs`。求解器不进入游戏运行依赖图。

经典几何与 [GNOME 官方 Klotski 的 Red Donkey 开局](https://raw.githubusercontent.com/GNOME/gnome-klotski/master/src/klotski-window.vala)核对，只参考布局事实，没有复制第三方求解代码。[清华大学出版社官方试读](https://www.tup.tsinghua.edu.cn/upload/books/yz/077027-01.pdf)印刷页35—36用于名称／底中央出口核对，其中81步使用其他口径，未用于本项目最短步数结论。

## 操作与生命周期

点击棋块选中后使用四向按钮，也可在棋块上沿直线拖动；选中高亮显示当前块。拖动先达到0.55格阈值，主轴幅度至少是另一轴的1.15倍才锁定方向轴，之后只在该轴移动；每次事件最多尝试5格，遇阻停止。多指取消当前拖动。

提供悔一步、重开、换关、玩法、暂停、分享和大厅。关卡菜单取消／选当前关卡恢复此前暂停状态；选择其他关卡或重开时，有保留移动历史则先确认覆盖，取消后保留原局并暂停。零步初局或已通关局可直接新开，最佳步数保留。过期菜单／确认回调不会改写后来局面。

第一次成功移动后开始计时和音乐。持久化 `started` 标记：悔棋回0步也不停止已经开始的计时，只有重开重置；终局停止计时。暂停、后台、返回大厅、分享、旋屏与合法未结束存档恢复后，需手动继续。宿主每100ms请求推进，单帧最多计入1000ms；音乐沿用公共播放器，没有独立长期定时器。

## 存档、最佳与兼容

新键 `games-between:huarongdao:save:v1`、外层version 1，保存一个当前局的 `round`、`elapsedMs`、`started` 和各关 `best`。**最佳只记录通关最少步数，不记录最快用时**；计时用于当前局展示。悔棋后的当前步数是保留路径长度，不累计已撤回的尝试。

每次合法移动、撤销、新开、暂停及宿主save保存；进行中每累计5秒有效时间也保存。未结束合法存档恢复为暂停，终局保持完成；选中块与未完成手势不恢复。

恢复从对应固定初盘逐步重放最多10000条移动历史，拒绝非法移动、终局后的追加移动，核对棋块顺序、ID、标签、尺寸、坐标和最终状态。损坏或不兼容当前局回退入门新局，合法的每关最佳仍可保留；合法用时与 `started` 标记恢复，历史非空或用时非零也视为已开始。存储失败时提示，仍可游玩。

已有游戏key、旧分享与私有开发工具配置不变。入口分享仅 `g=huarongdao`，不替换接收者当前局；回滚旧代码只失去新游戏入口。
